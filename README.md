# Warehouse in Lurín — Interactive Underwriting Model

Hypothetical 5-year underwriting model for a 10,000 m² logistics warehouse in Lurín, Lima.

🚀 **Live demo:** https://joseantonioescobar.github.io/warehouse_in_Lurin/

## What it does
- Re-underwrites the deal in real time across five levers: entry price, exit cap rate, rent growth, occupancy and opex.
- Live sensitivity matrices (IRR by price × exit cap; rent growth × occupancy path).
- Frozen stress tests that show which assumptions the investment actually depends on.
- Market context sourced from public reports (JLL Lima Logistics, H1 2026).

## Built with
HTML, CSS and vanilla JavaScript. The model logic runs entirely in the browser.
